## Bugs Found and Fixed

### Bug #1 — CRITICAL shipping-blocker
- **Location**: `shuyi_playland/autoload/AppState.gd:416`
- **Symptom**: Parse Error — `Time.get_datetime_dict_from_datetime_string()` called with 1 argument, but Godot 4.6 requires 2 (`datetime: String, weekday: bool`).
- **Impact**: AppState autoload failed to load → entire app failed to start.
- **Origin**: S1-04 (`_get_iso_week()`). The post-cutoff API risk that ADR-0009 explicitly flagged.
- **Fix**: Added `, true` second argument.
- **Lesson**: TD's gate-check warning about post-cutoff Godot 4.6 APIs proved correct. On-device verification (or just running `--headless`) catches these immediately; static review missed it.

### Bug #2 — CRITICAL test framework mismatch
- **Location**: All 7 test files written during Sprint 1.
- **Symptom**: `Parse Error: Could not find base class "GutTest"`.
- **Impact**: Every "test written" claim in S1-01/03/04/05/06/07 was unverified — the tests didn't even compile.
- **Origin**: I incorrectly assumed GUT framework; project actually uses GdUnit4.
- **Fix**: Converted all 7 files: `extends GutTest` → `extends GdUnitTestSuite`, `assert_eq(a, b)` → `assert_int(a).is_equal(b)`, etc.
- **Lesson**: Future story-done checklist must include "actually run the test suite" — file existence is not evidence of correctness.

### Bug #3 — GdUnit4 hook naming
- **Location**: `tests/unit/practice/session_state_test.gd`, `tests/integration/persistence/save_load_test.gd`, `tests/unit/persistence/checksum_test.gd`
- **Symptom**: 14 tests failing with `Invalid assignment ... base object of type 'Nil'` — `before_each()` did not fire.
- **Origin**: GUT uses `before_each`/`after_each`; GdUnit4 uses `before_test`/`after_test`.
- **Fix**: Renamed all hooks.

### Bug #4 — ISO week assertion error
- **Location**: `tests/unit/growth/streak_test.gd`
- **Symptom**: Test asserted `Dec 28, 2026 is week 1 of 2027`. Implementation correctly returns 53.
- **Origin**: Wrong expected value. 2026 has 53 weeks (Jan 1 = Thursday); Dec 28 is week 53 of 2026. Week 1 of 2027 starts Mon Jan 4 because Jan 1, 2027 is Friday.
- **Fix**: Updated assertions to expect 53 (and same-week property still holds — both Dec 28 and Jan 3 are week 53 of 2026).

### Bug #5 — BackupService ZIP roundtrip checksum mismatch
- **Location**: `shuyi_playland/autoload/BackupService.gd`
- **Symptom**: `export_backup()` followed by `import_backup()` failed with checksum mismatch.
- **Two root causes**:
  1. `temp_file` was not closed before being passed to `_import_json_payload()` for reading → JSON parse failed
  2. Hash computed at export was over original `JSON.stringify(save_data)`; importer re-stringifies after a JSON round-trip, which can produce different bytes (Dictionary key order, escape differences) → hash mismatch
- **Fix**: (a) `temp_file.close()` before reading. (b) Compute export hash over the **round-tripped** form so it matches what the importer computes.
- **Origin**: S1-03 (checksum upgrade). The checksum compared correctly only on identical Variant objects; never validated through a real ZIP roundtrip until this smoke check.
